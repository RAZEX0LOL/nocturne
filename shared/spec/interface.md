# Интерфейс

Проверяемых кейсов здесь нет: правила касаются того, что человек видит, а не того, что можно
сравнить двумя строчками JSON.

## Язык

Два языка: русский и английский. Исходный текст — русский, он же ключ перевода, поэтому код
остаётся читаемым, а переводы лежат одним списком:

| Платформа | Где лежит |
|---|---|
| iOS / iPad / Mac | `Nocturne/Resources/Localizable.xcstrings` |
| Android | `android/app/src/main/java/app/nocturne/music/Strings.kt` |
| Desktop | `desktop/src/i18n.ts` |

По умолчанию язык берётся системный: русская система — русский, любая другая — английский.
На iPhone и Android этого достаточно, там язык приложения меняется в системных настройках;
на десктопе такой настройки нет, поэтому язык можно выбрать в самом приложении.

Подстановки помечаются фигурными скобками (`Треков: {n}`), а не порядковыми номерами: в переводе
части предложения могут меняться местами.

Сообщения ядра тоже видит человек, поэтому они переводятся наравне с остальным. Ядро при этом
не должно определять вид ошибки по тексту сообщения — для этого у ошибки есть отдельное поле.

## Тёмная тема и акцент

Основа тёмная на всех платформах; меняется акцент (фиолетовый, мятный, рассвет, серый).
