# Офлайн, загрузки и своя музыка

## Три источника звука

1. **Файлы на устройстве** — то, что человек сам положил в приложение. Идентификатор начинается с
   `local:`, дальше хеш пути. Сервер для них не нужен вообще.
2. **Загрузки с сервера** — копии серверных треков, сохранённые для офлайна. Идентификатор
   серверный, поэтому такой трек остаётся тем же самым треком: избранное, рейтинг и скробблинг
   работают.
3. **Поток с сервера.**

Порядок выбора при воспроизведении: файл на устройстве → загруженная копия → поток. То есть если
трек уже есть на диске, сеть не трогается никогда.

## Поведение без сети

Сервер недоступен — это не ошибка, а режим. Главная показывает то, что лежит на устройстве и в
загрузках, медиатека и треклисты открытых альбомов берутся из кеша, нескачанные треки видны, но
приглушены и не запускаются (вместо этого — понятное объяснение, а не молчаливый сбой).

Прослушивания копятся и уходят на сервер, когда связь вернулась.

Приложение обязано работать и вовсе без сервера: человек может никогда не подключать Navidrome и
пользоваться только своей музыкой.

## Своя музыка

Файлы лежат в открытой папке (`Music` внутри документов приложения), чтобы их можно было положить
туда и снаружи — через файловый менеджер или проводник. Приложение периодически пересматривает
папку: новые файлы появляются в библиотеке, удалённые исчезают.

Поддерживаются MP3, M4A, AAC, ALAC, FLAC, WAV, AIFF. Название, исполнитель, альбом и обложка
читаются из тегов; если тегов нет — из имени файла и папки, причём ведущее число в имени
(`03 - Название`) понимается как номер трека.

Способы добавить: выбрать файлы, выбрать папку целиком, скачать по прямой ссылке, скачать через
встроенный браузер, получить из другого приложения через системное «Поделиться».

## Загрузки

Идут в фоне и переживают закрытие приложения. Настройки: только по Wi-Fi, ограничение объёма,
автоматическая загрузка избранного. Очередь загрузок видна, каждую можно отменить, скачанное —
удалить.

Загруженный файл лежит рядом со своими метаданными, чтобы после перезапуска библиотека собиралась
без обращения к серверу. Там же сохраняется обложка: серверный адрес без сети не откроется, а
временный кеш картинок система может вычистить — и офлайн-библиотека осталась бы пустыми квадратами.

## Изоляция и подготовка очереди

Серверные загрузки, обложки, каталог, задания и отметки принадлежат аккаунту (сервер + пользователь).
Одинаковые ID на разных серверах не означают одинаковую музыку. Старые файлы без владельца
сохраняются отдельно, пока их принадлежность нельзя установить надёжно.
Каталог хранится на диске и доступен сразу после запуска; обновление сети не очищает сохранённое.
Задание загрузки хранит аккаунт, метаданные и качество, но не пароль и не подписанный URL.
После перезапуска приложение возобновляет задания активного аккаунта с новой подписью запроса.
Автоподготовка очереди включается отдельно: ближайшие 3 трека (до 15 минут), только на
неограниченной сети, до 256 МиБ на аккаунт. Она не удаляет ручные загрузки; старые автоматические
копии вытесняются первыми. При нехватке места или смене сети подготовка ждёт подходящих условий.
