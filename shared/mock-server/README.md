# Поддельный Navidrome

Крошечный сервер на стандартной библиотеке Python: отвечает по протоколу Subsonic, отдаёт один
альбом, три коротких WAV-трека и цветные обложки. Нужен, чтобы проверять приложение целиком —
вход, листание библиотеки, воспроизведение, загрузки, офлайн — без настоящего сервера и без чужой
музыки.

```sh
python3 shared/mock-server/mock_navidrome.py        # треки по 8 секунд
python3 shared/mock-server/mock_navidrome.py 60     # треки подлиннее, для проверки перемотки
```

Сервер слушает `http://127.0.0.1:4533`. В приложении такой адрес принимается: обычный HTTP
разрешён только для локальной сети (см. `shared/cases/credentials.json`). Логин и пароль — любые
непустые, подпись не проверяется.

Симулятор iOS ходит на localhost хоста напрямую. Эмулятор Android видит хост-машину как
`10.0.2.2`, поэтому там адрес будет `http://10.0.2.2:4533`.

Полезные мелочи для проверок:

- обложки отдаются как PNG нужного размера, так что видно кеширование;
- поток одного трека можно один раз уронить в 500, чтобы проверить повторные попытки;
- скробблинг принимается и логируется — видно, что отложенные отправки доходят.
