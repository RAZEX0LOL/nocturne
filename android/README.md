# Nocturne for Android

Отдельное нативное приложение на Kotlin и Jetpack Compose. Минимальная версия — Android 8 (API 26). Воспроизведение реализовано через Media3 ExoPlayer и MediaSessionService.

## Открыть и собрать

Открой эту папку в Android Studio. Установи Android SDK Platform 36 и Build Tools 36.0.0. Укажи SDK в `local.properties` или переменной `ANDROID_HOME`.

```sh
./gradlew :core:test :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Это debug-сборка для тестирования, не подписанный релиз для Google Play.

Требуются JDK 17+ и версия JDK, поддерживаемая Gradle 9.3.1. В рабочем окружении используется JDK 25. Gradle Wrapper и дистрибутив проверяются по SHA-256.

## Проверки

```sh
# Проверка API даже без Android SDK:
./gradlew -PcoreOnly :core:test

# На отдельном эмуляторе без сохранённого аккаунта:
./gradlew :app:connectedDebugAndroidTest
```

## Что умеет

- Вход в Navidrome, тёмная главная, альбомы, исполнители, плейлисты, избранное и поиск.
- Своя музыка с телефона: папка приложения `Music`, добавление файлов и целых папок системным
  выбором, чтение тегов и обложек, номер трека из имени файла.
- Загрузки с сервера для прослушивания без сети; рядом с файлом лежат его метаданные.
- Работа без связи: сокращённое меню, нескачанные треки приглушены, прослушивания копятся и
  уходят на сервер, когда связь вернулась. Можно пользоваться и вовсе без сервера.
- Плеер: очередь из общего ядра (честное перемешивание, три режима повтора), эквалайзер на семь
  полос с пресетами, таймер сна, текст песни, избранное.
- Настройки: качество потока отдельно для Wi-Fi и мобильной сети, выравнивание громкости,
  загрузки только по Wi-Fi, автозагрузка избранного, четыре акцента оформления.
- Фоновый аудиосервис, уведомление и системное управление музыкой через MediaSession.
- Деморежим с вымышленными альбомами и процедурными обложками без аудиофайлов.

## Проверка без настоящего сервера

```sh
python3 ../shared/mock-server/mock_navidrome.py &
./gradlew :app:installDebug
adb shell am start -n app.nocturne.music/.MainActivity \
  -e server "http://10.0.2.2:4533" -e user test -e password test
```

Параметры входа принимает только отладочная сборка — в релизе этого пути нет. Эмулятор видит
компьютер как `10.0.2.2`.

## Хранение данных

Адрес, логин и пароль вводятся только в приложении. Учётные данные зашифрованы AES-GCM ключом из Android Keystore. Зашифрованный файл хранится в `noBackupFilesDir`, резервное копирование приложения отключено. API и потоки используют HTTPS; HTTP и самоподписанные сертификаты не поддерживаются. Дисковый кэш обложек выключен, токены не выводятся в лог приложения.

Сервер должен поддерживать транскодирование в MP3 для выбранного профиля потока (до 320 кбит/с). Обычный HTTP разрешён платформой, но само приложение пускает его только в домашнюю сеть: адрес
проверяется в ядре и покрыт общим контрактом. Реальное аудио, наушники и Android Auto стоит
проверить на своём устройстве.

Архитектура: `core` — модели и клиент OpenSubsonic без зависимости от Android; `app` — Compose, Android Keystore, ViewModel, MediaController и MediaSessionService. Swift-код iOS в Android-приложении не используется.
