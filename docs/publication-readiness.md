Изменение видимости выполняется отдельно от этой подготовки.

  [инвентаризации](dependency-licenses.json): 178 записей npm, 569 Rust и 125 Android.
  Указаны границы охвата и SHA-256 входных файлов; это снимок зависимостей на дату проверки.

## Проверка секретов и данных

- Gitleaks 8.30.1, архив инструмента проверен по SHA-256 из официального выпуска.
  Проверены все 85 коммитов, достижимых из локальных и удалённых веток до подготовки.
- Единственное исходное срабатывание — публичный ключ проверки обновлений Tauri.
  Тип ключа проверен; добавлено исключение по конкретному fingerprint, без отключения правила.
  Повторный проход истории: 0 находок.
- 952 исторических blob-объекта сопоставлены с 7 действующими приватными значениями
  из локальных конфигураций: 0 совпадений. Значения не включены в отчёты.
- Проверены архивы логов 71 завершённого запуска Actions и 83 артефакта:
  поиск известных приватных значений и типовых ключей/токенов, состав архивов,
  дополнительная проверка содержимого APK. Логи дополнительно проверены Gitleaks.
  Находок нет. Полная декомпиляция установщиков и сторонних бинарников не выполнялась.
- На дату проверки Issues, PR, комментариев к Issues и Releases в репозитории исходников нет.
  Официальные установщики находятся в отдельном репозитории `nocturne-releases`.
- Абсолютные пути к домашней папке в текущих текстовых отчётах заменены на `<repo>`.
  История Git не переписывалась; имя и почта автора коммитов остаются в истории.
- `.gitignore` дополнен ключами, сертификатами, provisioning-профилями и конфигурациями XCTest.
  Данные аудита и загруженные логи остаются в игнорируемом `build/`.

Это результаты конкретных проверок, а не гарантия обнаружения любого возможного секрета.
После новых изменений и перед изменением видимости сканирование нужно повторить.

## Репозиторий и CI

- README на русском и английском: установка из App Store, локальные файлы, демоверсия,
  устройство репозитория и сборка без ключей автора.
- CONTRIBUTING, SECURITY, шаблоны Issues и PR; уязвимости сообщаются приватно.
- Actions закреплены по SHA; `contents: read`, без ключей официальной подписи.
  Настройки токена репозитория уже были read-only, одобрение PR из Actions запрещено.
- В CI добавлены сайт и Gitleaks по всей истории. Проверочные установщики сохраняются
  только по ручному запуску на 7 дней. Официальные подписанные релизы собираются отдельно.
- Старое падение Android CI вызвано заполненной квотой загрузки артефактов после успешной
  сборки. Исторические артефакты не удалялись. Обычные push / PR больше не копят установщики.
- Синтаксис workflow проверен actionlint 1.7.12; локальные ссылки новой документации проверены.
- Полная локальная проверка `python3 scripts/verify.py`: 13 PASS, 0 FAIL.
