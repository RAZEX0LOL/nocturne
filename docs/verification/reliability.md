## Границы проверки

Изолированное Tauri-приложение собрано и запущено, но инструмент управления компьютером
отказал в доступе к его окну. Ручная проверка нативного окна не выполнена; desktop UI проверен
в Chromium e2e. Windows проверен компиляцией, Linux — тестами логики определения сети;
живые проверки этих ОС не выполнялись. Два пропущенных Rust-теста требуют живого Discord
и отдельного нативного окружения с мок-сервером.

Пользовательский `project.pbxproj` не изменялся в ходе работы. Коммиты, push и выпуск
не выполнялись.
