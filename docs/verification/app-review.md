# App Review: демоплеер и подготовка аудио

## Замечание Apple от 26 октября 2026

Проверялась версия 1.0 (77), iPhone 17 Pro Max и iPad Air 11-inch (M3), iOS/iPadOS 27.0.1.
Отказ по 2.1(a): в демоплеере не воспроизводился ни один трек.

Причина подтверждена кодом: DemoLibrary содержал только метаданные, без источников аудио.
UI-тест ожидал предупреждение о невозможности воспроизведения и потому не ловил проблему.

Теперь в каталоге ресурсов приложения пять оригинальных инструментальных примеров AAC по
24 секунды, суммарно около 640 КиБ. Все демотреки имеют файловый источник. При первом
воспроизведении NSDataAsset атомарно извлекается в кэш; после очистки кэша восстанавливается
из ресурсов приложения. Сервер, аккаунт и интернет для этого не нужны. Демо не отправляет
скробблы на ранее подключённый сервер и не перезаписывает личный снимок очереди. Старые
снимки с демотреками не восстанавливаются в серверный или локальный режим.

`scripts/generate-demo-audio.py` воспроизводит фонограммы на Mac (Python, afconvert, ffmpeg).
Это синтезированные примеры проекта, без внешних музыкальных записей. Последний пример
специально содержит аудиодорожку с ID 7: плеер должен использовать реальный ID, а не предполагать 1.

В ходе проверки исправлена область нажатия строки альбома: пустое место внутри строки
теперь тоже открывает альбом.

## Редкий запуск без звука

Наблюдение пользователя: позиция движется, звук появляется после перезапуска трека.
Связь с EQ, плавными переходами и маршрутом вывода пока не установлена.

Найдена гонка: AudioEffects сначала устанавливал микс для ID 1, а затем мог асинхронно
заменить audioMix уже играющего AVPlayerItem. Теперь дорожка и эффекты готовятся до
добавления item в AVQueuePlayer — для текущего и следующего трека. Отменённая подготовка
не добавляет пропущенный item; запоздавший результат активации аудиосессии не меняет
состояние другого сеанса.

Это устраняет конкретную гонку, но исчезновение редкого сбоя на физическом устройстве
ещё нужно подтвердить. Движение ползунка в симуляторе само по себе не доказывает наличие
звука на Bluetooth/AirPlay или динамике телефона.

## Проверки

- `swift test`: 42 теста, 0 ошибок. Все пять файлов декодируются AVAudioFile, длительность
  совпадает с каталогом, первые аудиобуферы содержат ненулевой сигнал; проверен track ID 7.
- Release UI, чистый iPhone 17 Pro Max / iOS 26.0.1: 2 теста, 0 ошибок.
  Обычная кнопка деморежима → альбом → все пять треков, движение позиции, пауза,
  продолжение, перемотка и автоматический переход; отдельно навигация и поиск.
- Release UI, iPad Air 11-inch (M3) / iPadOS 26.0.1: 1 тест, 0 ошибок. Те же пять файлов,
  пауза/продолжение, ручные и автоматические переходы. Тест явно выбирает кнопки полного
  плеера, поскольку мини-плеер тоже присутствует в дереве доступности iPad.
- Артефакты iPad: `build/demo-review-ipad-summary.json`, `build/demo-review-ipad-final.log`,
  `build/demo-review-ipad-attachments/`.
- Артефакты iPhone: `build/demo-review-phone-summary.json`,
  `build/demo-review-phone-verified.log`, `build/demo-review-phone-attachments/`.

Первый прогон с неверным фильтром выбрал 0 тестов и не засчитывается.
Последний Debug-прогон на iPhone / iOS 26.0.1: 3 теста, 0 ошибок — все демофайлы,
серверный поток с настоящими HTTP range-запросами, переход к похожему треку, скорость 1,5×
и фоновое разрешение цветов. Включает защиту от восстановления демоочереди после смены режима.
Артефакты: `build/demo-review-stream-summary.json`, `build/demo-review-stream-verified.log`.

iOS 27.0: сборка успешна, XCTest не запустил тестовый процесс за три минуты; прогон остановлен
и не засчитывается. Проверка физического iPhone/iPad с iOS/iPadOS 27.0.1 остаётся необходимой
перед повторной отправкой в App Review. Скриншоты успешных iPhone/iPad тестов просмотрены.
